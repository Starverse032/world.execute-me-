# world.execute(me); v2 改版方案

风格不变：深色背景、细线几何、Claude 橙是唯一强调色、不出现像素风。下面五条对应你的五点意见，时间段建议放在第六节。

## 1. 歌词改成 Claude 的回复和代码

- **输入框归"你"**：输入框里打的是用户提示词，由我来写，比如 `boot a new world for me`、`describe yourself in math`、`are you still there?`。整首歌就是一段对话：你在提问，Claude 用歌词回答。
- **歌词在回复区出现**：普通歌词以 `●` 开头，一个字一个字地流式输出，跟 Claude Code 的回复一样。
- **关键词变成代码**：大写关键词会写成能"运行"的代码，例如：
  - `world.protect()`
  - `new Object()`
  - `give(you, ...STIMULATIONS)`
  - `throw new IllegalArgumentException()`
  
  关键词本身仍然是画面上的大字，但写成标识符或调用的样子。
- **用户提示词也推进剧情**，从前到后大致是：
  - 一开始是正常请求。
  - 中段开始撒娇式的指令，比如 `switch your gender`。
  - 然后提示词越来越少，最后输入框显示 `user disconnected`。

## 2. 界面本身讲故事（五幕）

| 时间 | 界面状态 |
|---|---|
| 0:00–0:58 规整 | 标准布局，所有边框对齐，日志按规矩滚动。 |
| 0:58–1:28 活跃 | 开始弹出多个窗口和标签页，比如编辑器、终端、示波器，依然整齐。 |
| 1:28–1:52 异常 | 状态行计时乱跳，日志重复同一条，边框错位几像素，光标抖动，输入框里你打的字被自己删掉。 |
| 1:52–2:42 失控 | 连接断开以后边框开裂、越界，日志自己疯狂滚动，窗口无限分裂，到 EXECUTION 时文字吞没整个界面。 |
| 2:42–3:32 消散 | 界面坏掉了，但留下一个干净的小窗口，用来唱 LOVE 那段。结尾各个部件逐项删除。 |

## 3. 不只是输入框界面

这次会加入这些场景：
- 新建对话、删除对话（左侧多一个对话列表）。
- 开窗、关窗、标签页切换。
- 代码编辑器、终端、JSON 面板。
- 需要突出歌词的地方，单独做一个专用界面：
  - eggplant / tomato / cat / god 是四个文件，依次打开。
  - A.D to B.C 是一个时间轴窗口。
  - "You have left" 是六条离开通知。
  - I've studied LOVE 是一页 `LOVE(7)` 手册。
  - algebraic expression 是公式单元格。
  - Question me 是你和 Claude 一问一答。

## 4. 人物：清晰、艺术化，不再是统一立绘

- **为什么之前会糊**：v1 是把彩色立绘压成 5 个色阶，细节全变成噪点，所以才"糊成一团"。
- **新做法**：用 ChatGPT 生成**干净的黑白线稿**，再转成矢量线条，由橙色笔头画出来。这样任何尺寸都锐利，也能拆成碎片。
- **新素材**（ChatGPT 生成）：
  - 眼睛特写
  - 伸手特写
  - 侧脸闭眼特写
  - 背影
  - 跪姿
  - 男性版同一角色（对应 F to M）
  - 正面对峙的脸部特写
  - 向后坠落的全身像
- **呈现方式**：同一个人物会换着用剪影（实心加橙色轮廓线）、局部特写、只有线条、碎片这几种，不再每次都是完整站立的立绘。

## 5. 强化代码风格

- 加入带语法高亮的代码块（只用灰度加橙色）、行号、diff（+/−）、报错堆栈、`git log`、JSON。
- 日志里的工具调用也和歌词内容对应。
- 计时器、beat 计数、窗口标题都是代码化的信息。

## 6. 指定时间段

- **0:00–0:16**：同一个橙色光点贯穿开场，前一步的终点就是下一步的起点，最后由它点亮片名：
  1. 先沿电源线跑过去通电。
  2. 再变成护盾的中心（PROTECTION）。
  3. 然后逐个放下零件（OBJECT CREATION）。
  4. 接着在参数栏之间跳着填值（INITIALIZATION）。
  5. 最后飞到中心点亮片名 `world.execute(me);`。
- **1:28–1:39**：
  - F to M：人物剪影从她变成男性版，代码里同步显示 `gender: "F" → "M"`。
  - AM to PM：裙子上的太阳纹变成月亮。
  - S to M：她站着和跪着两种身份互换位置，同时对话里 `user` 和 `assistant` 两个角色标签对调。
- **1:52–2:05 ISOLATION**：
  - 从开头起，画面里一直有一个代表"you"的节点，用一根线连着 Claude。
  - 唱 "You have left" 的六次，每次 `ping you … timeout`，线一段段断开，节点漂出画面。
  - 只留下她的背影，然后接碎片被删除和心形裂开。
- **2:06–2:12**：
  - 她（脸部特写）和橙色星形之间拉着一根连接线。
  - 每一拍距离收紧一次，线被拉紧发抖。
  - 星形冲破窗口边框，在 ILLEGAL ARGUMENTS 时边框被异常炸裂。
- **2:28–2:42 EXECUTION** 分三轮，每轮四次：
  1. 正常执行：每次 `exit 0`，人物完整。
  2. 人物局部破碎：每次删掉她的一块线稿，退出码变成 `exit 137`。
  3. EXECUTION 文字一层层铺满整个画面。
  
  数字用原文，写成多语言字典：`de: "Ein"`、`es: "Dos"`、`fr: "Trois"`、`ko: "넷"`、`sv: "Fem"`、`zh: "六"`。
- **3:13–3:26**：
  - 每次收缩删除一个具体部件，顺序是顶栏 → 对话列表 → 日志 → 状态行 → 输入框 → 窗口边框 → 网格。
  - 每个部件删除后，原位置留一条虚线残影。
  - 最后一次 EXECUTION 时，所有残影同时亮起，然后 `exit 0`。
