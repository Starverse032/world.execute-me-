# world.execute(me); — 非官方同人 MV 源码

Mili《world.execute(me);》的同人动画 MV。画面是一段 Claude 对话：输入框里是"你"的提示词，Claude 用歌词和代码回答。界面跟着歌曲从规整、异常、失控走到逐项删除。全片用 [Remotion](https://www.remotion.dev/)（React）以代码生成，可以输出 1920×1080、30 fps，也可以输出 4K 120 fps HDR，片长 3:43。

> 本视频为非官方同人作品，与 Mili、Anthropic、OpenAI 均无关联。
>
> - 视频作者：Starverse
> - 歌曲原作：Mili
> - Claude 虚拟形象原案：Bilibili@ZipZipPipe
> - 源码开发：Opus 5.5
> - 审核校订：GPT 6.1 Sol
> - 人物素材：Image 2.5

创作过程中每一轮的对话记录见 [CONVERSATION.md](CONVERSATION.md)。

## 在本地生成视频

### 1. 下载源码

```bash
git clone https://github.com/Starverse032/world.execute-me-.git
cd world.execute-me-
```

不用 git 的话，点 GitHub 页面上的 **Code → Download ZIP**，解压后在这个文件夹里打开终端。Windows 上可以用 PowerShell，在文件夹空白处按住 Shift 再右键，选"在此处打开 PowerShell 窗口"。

### 2. 安装依赖

```bash
npm install
```

### 3. 放入音频

把歌曲的 mp3 复制到 `public/` 文件夹，并改名为 `song.mp3`：

```
public/song.mp3
```

音频必须是完整的原曲（约 3:32），从第 0 秒开始，不能剪掉开头。画面里所有节拍和歌词都按原曲的时间轴对齐。

### 4. 预览（可选）

```bash
npm run studio
```

浏览器会打开 Remotion Studio（通常是 http://localhost:3000）。在左边选 **Release** 就能边拖时间轴边预览。预览只是看效果，导出视频请用下一步。

### 5. 渲染

```bash
npm run render
```

渲染完成后，成片在 `out/world-execute-me.mp4`，规格如下：

- 1920×1080，30 fps；
- 3:43 长，结构是 2.5 秒观看提示、3:32 正片、9 秒无声片尾（署名和声明）；
- H.264 编码，crf 18，约 110 MB。

渲染时间取决于 CPU，4 核机器大约 7 分钟。终端会显示进度。

### 6. 加上中文字幕

把字幕复制到视频旁边，改成和视频同名（例如 `world-execute-me.srt`）。大多数播放器（PotPlayer、VLC、IINA 等）会自动加载。`Release` 开头有 2.5 秒观看提示，用 `subtitles/world.execute(me)_release_zh.srt`（字幕从 0:02.600 开始）；只有正片的 `FullMV2` 用 `subtitles/world.execute(me)_zh.srt`。需要改提示时长时，用 `python scripts/shift_srt.py <输入.srt> <输出.srt> <秒数>` 重新生成。

### 7. 压缩（可选）

原画质文件较大。想要更小的文件，可以用 Remotion 自带的 ffmpeg 压一遍，下面的码率出来约 24 MB：

```bash
npx remotion ffmpeg -i out/world-execute-me.mp4 -c:v libx264 -b:v 740k -c:a aac -b:a 112k out/world-execute-me_small.mp4
```

### 8. 4K 120 fps HDR 母版（可选）

```bash
npm run render:4k
```

成片在 `out/world-execute-me_4k120hdr.mp4`，规格如下：

- 3840×2160，120 fps，HEVC Main 10，BT.2020 + PQ，带 HDR10 静态元数据（MaxCLL 400，MaxFALL 100）；
- 音轨是 `public/song.mp3` 的原始 mp3 帧，不重新编码；前面加了 95 个静音帧，正片音乐比提示卡结束晚 6.7 ms，不到 1 帧；
- 字幕用 `subtitles/world.execute(me)_release_zh.srt`。

需要 NVIDIA 显卡：Remotion 自带的 `libx265` 只能编 8-bit，`hevc_nvenc` 才能编 10-bit。约需 30 GB 硬盘空间。在 24 线程的笔记本上，帧渲染约 70 分钟，编码约 40 分钟。分段帧存在 `out/4k120/`，中断后再运行会从未完成的分段继续；想改调色，用 `node scripts/render_4k120.mjs --regrade`，不必重新渲染画面。

几点说明：

- **120 fps**：动画按时间计算，所以连续运动是真正的 120 帧。逐字显示、故障闪烁这类按固定节奏跳变的效果，节奏不变。
- **HDR**：Chrome 只能截取 8-bit sRGB，所以这是在 SDR 渲染结果上做的 HDR 调色，不是原生 HDR 渲染。调色在线性光下按每个像素最大的通道缩放，色相不变：暗部基本不动（背景约 0.8 尼特），高光提升（奶油色约 310 尼特，橙色约 250 尼特，纯白 400 尼特）。参数在脚本开头的 `PEAK_NITS`、`EXPONENT`。
- **4K 人物素材**：`public/la3x/` 是 `scripts/upscale_art.py` 把平涂素材放大 3 倍的结果，颜色不变，边缘变平滑。线条和文字本身是矢量的。

## 其他可渲染的版本

`npx remotion render src/index.ts <名字> out/<文件名>.mp4` 可以单独渲染下面任意一个：

| 名字 | 内容 |
|---|---|
| `Release` | 最终版：观看提示 + 正片 + 片尾署名与声明（`npm run render` 渲染的就是它） |
| `Release120` | 同一内容，120 fps（`npm run render:4k` 用它渲染 4K HDR 母版） |
| `FullMV2` | 只有正片（3:32，v2），`npm run render:mv` |
| `IntroCard` / `OutroCard` | 只有片头或片尾卡片（无声） |
| `FullMV` | 完整版 v1（被 v2 取代的上一版） |
| `DemoV3` | 定稿前的 46 秒风格 demo |
| `V4Kit` | v2 界面组件一览，开发用 |

## 进阶：重新处理素材

以下脚本只在修改素材时才需要，渲染视频用不到。Python 脚本需要 Python 3.10+，并安装依赖：

```bash
pip install numpy pillow scikit-image scipy opencv-python
```

| 脚本 | 用途 |
|---|---|
| `scripts/lineart.py`、`scripts/la_all.sh` | 把 ChatGPT 生成的黑白线稿转成 `public/la/` 里的矢量笔画和墨线图。用法：`bash scripts/la_all.sh <放 la_*.png 的文件夹>` |
| `scripts/char_v3.py` | v1 的扁平色块人物处理 |
| `scripts/beats_full.py` | 从音频检测节拍，生成 `src/beats.json`。需要 `public/song.mp3` 和系统 ffmpeg |
| `scripts/make_srt_full.py` | 用 LRC 和 `docs/lyrics_zh.json` 生成中文字幕。需要你自己的 LRC 文件，放在 `docs/lyrics.lrc`（已在 `.gitignore` 里）。用法：`python scripts/make_srt_full.py <输出.srt> 211.96 [偏移秒数]`。`FullMV2` 偏移为 0，`Release` 开头有 2.5 秒提示卡，偏移为 2.5 |
| `scripts/stills.mjs` | 批量导出单帧截图，用来检查画面：`node scripts/stills.mjs Release 0.5 300 900 1800` |
| `scripts/render_4k120.mjs` | 渲染 4K 120 fps HDR 母版，见第 8 步 |
| `scripts/upscale_art.py` | 把平涂人物素材放大到 `public/la3x/`（需要 Pillow） |
| `scripts/shift_srt.py` | 给字幕整体加偏移 |
| `scripts/fetch_fonts_v3.py` | 重新下载 v1 的子集字体 |

## 常见问题

- **渲染报错，提到 `song.mp3` 找不到或 404。** 第 3 步的音频没有放好。检查文件是否在 `public/song.mp3`，名字是否完全一致。
- **Chrome 下载失败。** 网络不通时，可以指定本机已安装的 Chrome 或 Chromium：
  ```bash
  npx remotion render src/index.ts Release out/world-execute-me.mp4 --browser-executable="C:\Program Files\Google\Chrome\Application\chrome.exe"
  ```
- **内存不足或电脑很卡。** 在渲染命令后加 `--concurrency=2`，减少同时渲染的帧数。
- **画面和音乐对不上。** 你的音频和原曲长度或开头不同，比如前面多了静音，或者用的是剪辑版。请换成完整原曲。
